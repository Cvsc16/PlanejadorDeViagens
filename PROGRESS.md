# Progresso: Planejador de Viagens

## 1. Estrutura Inicial
- [x] Criar projeto Android com Kotlin

## 2. Funcionalidades Obrigatórias
### Tela Inicial
- [x] Botão "Começar" para iniciar o planejamento
- [x] Mensagem introdutória: "Calcule o custo estimado de sua próxima viagem!"

### Fluxo de Preenchimento (3 Etapas)
- [x] **Etapa 1:** Entrada de Distância (km) + Botões "Próximo" e "Voltar"
- [ ] **Etapa 2:** Entrada de Consumo médio (km/L) + Botões "Próximo" e "Voltar"
- [ ] **Etapa 3:** Entrada de Preço médio do combustível + Botões "Próximo" e "Voltar"

### Tela de Resultado
- [ ] Cálculo da fórmula: Custo = (Distância ÷ Consumo) × Preço
- [ ] Exibição do resultado (Consumo, Preço, Custo Total)
- [ ] Botão "Planejar Outra Viagem" para reiniciar o fluxo
